# 模具工步排产系统 — 概述

独立子项目，与原一号线 `src/App.jsx` 分离。目录：`mold-scheduler/`。

## 启动

```bash
npm run dev:mold    # 开发，默认 5174
npm run build:mold  # 构建到 dist-mold/
```

## 业务范围

模具装配 **18 道合并工步**（M1～F2），用 DAG 表达并行与汇合（如 M1/M2/H1/A1 多路汇入 Z1）。

## 两阶段模型

| 阶段 | 做什么 | 人员怎么用 |
|------|--------|------------|
| **排产** | 定时间、房间、DAG 顺序 | 用人数**上限**占产能（保守） |
| **派工** | 定具体是谁 | 在 min～max 间按空闲 + 等级派实际人数 |

固定人数 = `workersMin = workersMax`；仅填 `workers` 时自动视为 min=max。

## 核心约束

- **DAG**：前置工步全部完成后才可开工
- **房间**：工步×房间 0/1 矩阵；同房同时仅一单
- **班次**：按工作日、上下班时段排程
- **总人力**：各时刻在制任务占用人数之和 ≤ 在岗上限
- **等级派工**：L2～L5 累积资格；**不降级**；不足标 SHORTAGE

## 主要模块

| 路径 | 职责 |
|------|------|
| `data/opsSeed.js` | 工步种子、房间矩阵、默认人员 |
| `scheduler/dag.js` | 拓扑排序、环检测、人数归一化 |
| `scheduler/greedy.js` | 贪心排产主流程 |
| `scheduler/shift.js` | 班次、房间时间槽、人力占用 |
| `scheduler/workersRange.js` | 人数区间 min/max |
| `scheduler/staffAssign.js` | 按姓名派工、负载均衡 |
| `scheduler/rooms.js` | 房间矩阵解析与校验 |

## 界面（Ant Design）

1. **工步配置** — DAG、房间资格、工时、等级、人数区间  
2. **约束参数** — 班次、房间列表、人员及等级  
3. **排产计划** — 批次与优先级  
4. **排产结果** — 甘特图（色块显示工步 ID，悬停看全名）、工单表、人员排班  

## 甘特图展示约定

- 色块内：**工步 ID**（M1、J1 等），窄条自适应字号，极窄时 ID 标在条外  
- 悬停 tooltip：合并工序名 · ID · 批次
